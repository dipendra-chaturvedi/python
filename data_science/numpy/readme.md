# NumPy Basics
---

## What is NumPy?

* **NumPy** = **Numerical Python**
* Python library used for **numerical and data operations**.
* Its main object is the **NumPy array**.

## Why use NumPy?

* Provides **fast numerical calculations**.
* Makes operations on **large datasets** easier.
* Provides useful functions such as:

  * `np.mean()` — Average
  * `np.sum()` — Total
  * `np.max()` — Maximum value
  * `np.min()` — Minimum value

## When to use NumPy?

Use NumPy when working with:

* Numbers
* Arrays
* Matrices
* Numerical datasets
* Data analysis
* Machine Learning

NumPy is commonly used **before or alongside Pandas and Machine Learning**.
